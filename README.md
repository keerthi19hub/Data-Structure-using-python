## Topics Covered

### Linear Data Structures
| Structure | Operations Implemented |
|-----------|----------------------|
| **Array / List** | Insert · Delete · Search · Reverse · Rotate |
| **Stack** | Push · Pop · Peek · Balanced parentheses |
| **Queue** | Enqueue · Dequeue · Circular Queue · Priority Queue |
| **Linked List** | Singly · Doubly · Circular · Reverse · Merge |
| **Deque** | Double-ended operations |

### Non-Linear Data Structures
| Structure | Operations Implemented |
|-----------|----------------------|
| **Binary Tree** | Inorder · Preorder · Postorder traversal |
| **BST** | Insert · Search · Delete · Height |
| **Hash Table** | Chaining · Open addressing |
| **Graph** | BFS · DFS · Adjacency list/matrix |
| **Heap** | Min/Max heap · Heapify |

### Algorithms
| Category | Algorithms |
|----------|-----------|
| **Sorting** | Bubble · Selection · Insertion · Merge · Quick · Heap sort |
| **Searching** | Linear · Binary · Jump search |
| **Recursion** | Factorial · Fibonacci · Tower of Hanoi · Subset generation |
| **Dynamic Programming** | Fibonacci (memoisation) · Knapsack · LCS |
